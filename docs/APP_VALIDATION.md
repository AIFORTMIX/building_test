## 构建

JDK 21 或兼容的 Android Studio JBR、Android SDK `platforms;android-37.0`、NDK `28.2.13676358`、CMake `3.22.1`。SDK 路径放在不提交的 `local.properties` 中。默认只构建 ARM64；模拟器使用 `-Pqingwei.abis=arm64-v8a,x86_64`。

```sh
./gradlew :app:assembleDebug :app:assembleRelease :app:testDebugUnitTest :app:lintDebug
```

Debug APK 使用标准调试签名；Release APK 经 R8 压缩但未配置发布签名，不能直接当作已签名安装包发布。CI 不需要签名或 AI 服务密钥。

## 已覆盖的模拟链路

本地单元测试使用真实 OkHttp、SSE 解析、会话管理器、认证 MCP HTTP 服务和工具编解码，仅在设备 ioctl 边界使用测试专属模拟设备。涵盖流式文本、中文和表情分片、工具参数碎片、多工具、工具结果回填、普通 JSON、畸形和截断响应、HTTP 错误、取消与鉴权。普通 JSON 和 SSE 工具调用在进入界面及执行前统一限制为单轮最多 32 个；超量响应直接报错，避免生成大量执行卡片。

会话测试涵盖消息和 ID 保留、草稿隔离、80 条一批加载历史、取消旧工具后切换、删除会话后迟到事件隔离、工具参数/状态/耗时。

Android 仪器测试执行实际 Compose 排版和交互，并通过 `/dev/null` 验证真实 JNI 库的非法长度和 errno 返回；这不等同于手机上的驱动联调。模拟器中不伪造 Root 权限或真实驱动连接状态。

## Markdown 与执行详情

原生 Compose 渲染 CommonMark 和已启用的 GFM 扩展：标题、段落、强调、删除线、引用、嵌套有序/无序列表、只读任务列表、代码、分隔线、表格、引用式链接和自动链接。代码与宽表格可横向滚动，正文可选择复制。

HTML 按原文显示，不启动 WebView 或脚本；图片显示替代文字和显式打开入口，不自动请求远程图片。链接只允许无嵌入凭据的 HTTP/HTTPS URL。数学公式、Mermaid 和其他未支持扩展保留为可读文字或代码，不保证所有 Markdown 方言的专用排版。

解析在后台按流式更新节流，完成消息使用按字符数限制的 LRU 缓存。过长或过深的输入回退为受限的文字预览，仍可复制完整原文。

执行卡片展示真实的工具准备、执行、完成、失败或取消等待状态，可展开参数、说明、返回内容和耗时。取消等待不代表撤销已提交的设备操作；界面明确标记结果未确认。不请求或伪造模型的私有思维链。命令若是工具参数的一部分，会在参数区原样展示；此项 UI 改动没有新增任意 Shell 执行能力。

每个会话独立保存草稿、消息 ID、加载范围和阅读位置；旧事件携带会话 ID，不能写进另一会话。上滑阅读时暂停自动跟随，返回会话恢复位置。会话当前存放在 ViewModel 内存中，进程被系统销毁后不会恢复历史，持久化仍待后续实现。

恢复长对话时先在后台准备阅读位置附近的 Markdown，再显示消息列表；缓存命中直接使用解析结果，避免先显示纯文本导致高度变化。阅读位置测试核对实际消息 ID 和像素偏移，并主动淘汰 Markdown 缓存验证重新加载。滚动条范围是估算值，不用它替代实际阅读位置。

手动阅读通过拖动开始事件暂停自动跟随，点击“回到最新”恢复跟随。发送和切换会话时收起键盘，避免输入焦点造成延迟视口变化；自动跟随同时响应 Markdown 高度与视口尺寸变化。测试等待惯性滚动和视口尺寸稳定后记录位置，并同时比较消息 ID、像素偏移和段落坐标，附带切换前后的截图。
