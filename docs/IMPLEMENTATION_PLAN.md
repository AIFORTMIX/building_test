## 2. 后台与目标进程验收

- [ ] 自动化验证外部 MCP 在后台、服务恢复、网络异常后的行为，以及长输出、分页和目标重启后的旧地址拒绝。

## 3. 静态分析

- [x] 工作区授权下的 ELF64 文件读取，检查格式、边界、内存上限和文件变化。
- [x] ELF 头、段、节、符号/导入导出、字符串分页查询。
- [x] 真正的 ARM64 指令解码、文件偏移与虚拟地址转换，以及符号定位。
- [ ] 静态分析界面与 MCP 工具可用；用自有测试二进制验证正常文件、剥离文件和畸形输入。

## 4. 动态调试

- [ ] 确定可运行的后端，真实支持附加、暂停、继续、单步、寄存器和调试事件，明确线程与进程的语义。
- [ ] 支持断点管理，以及目标退出、重启、exec、连接断开后的清理，不沿用旧地址。
- [ ] 调试界面和 MCP 接入同一状态机；不能把原始字节或硬件断点命中快照当作完整调试器。
- [ ] 自有目标进程的端到端验证及权限/平台不支持时的真实错误。若使用用户态 ptrace，不要求修改 KO；如果修改驱动或 ioctl，重新构建并验证 KO。
