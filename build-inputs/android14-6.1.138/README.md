# 手机构建包的内置导出 CRC 参考

这些文件来自用户提供的 AnyKernel3 bundle 中的 Image。
Module.symvers 覆盖内核内置的 8,152 个导出，不包含独立模块导出。
来源、Image 哈希和恢复校验见同目录的 JSON。

工作流将其作为编译完成后的只读比较依据，不替换构建内核的符号表，
也不改写生成模块的 CRC 或 vermagic。缺失导出、CRC 不一致或 release
不一致会中止交付。

导出的 /proc 配置没有作为强制编译输入：ABK 某些流程可能使用配置展示替代，
真实配置仍需由原始构建输出确认。CRC 与 release 校验通过，也不能替代
签名、CFI、完整结构体布局和真机运行验证。
